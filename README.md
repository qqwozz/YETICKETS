# 🎤 Фан-сайт концерта Канье Уэста

Всем привет! Это репозиторий моего небольшого проекта — простого сайта, посвященного концертам Канье Уэста.

Идея пришла спонтанно: я увидел, какой красивый и атмосферный сайт сделал Саня Харчевников в своем видео, и мне тоже захотелось попробовать повторить что-то подобное.

## 📂 Что внутри (структура)

Проект очень простой, без лишних сложностей. Вот какие файлы тут есть:

* `index.html` — главная страница сайта.
* `stadium.html` — дополнительная страничка (контент про стадионы/локации).
* `style.css`  — все стили и оформление.
* `IBMPlexMono-Regular.ttf` — стильный моноширинный шрифт, который я подключил для атмосферы.
* `planet.png` — картинка для декора.
* `yetickets.gif` и `yetickets.mp4` — медиафайлы, которые ты видишь выше.

## 💻 Технологии

Никаких тяжелых фреймворков, только база:

* **HTML5**
* **CSS3**

## 💭 Вдохновение и пара слов

Как я уже сказал, главным триггером послужило видео Сани Харчевникова про Канье Веста. У него сайт получился действительно стильным, и я захотел сделать свою версию.

Мой результат — это честная попытка повторить ту самую атмосферу. Где-то вышло нормально, где-то — чуть проще, чем хотелось бы, но я доволен тем, что получилось. 

## 🚀 Как посмотреть

Просто открой файл `index.html` в любом браузере — и всё заработает.
